## 1️⃣ PR #22 — CI 안정화

### 증상
PR #5~21 누적 13개 PR 의 GitHub Actions CI 가 `Failing after 1m` 으로 빠르게 실패 (Linux only — Windows 로컬은 133 passed 정상).

### 원인 가설
1. **`pytest --disable-socket` 이 Linux 에서도 일부 lib (httpx / requests / langfuse OTel) 의 *import 시점* socket 호출 차단** → collection 단계 import 에러
2. pytest-socket 의 `--allow-hosts=127.0.0.1` 누락
3. Linux py3.13 + langgraph 의존성 충돌 (낮은 가능성)

### 1차 액션
- `.github/workflows/ci.yml` 에서 `--disable-socket` 제거
- 진단 단계 추가: `python --version`, `pip --version`, `uname -a`, `pip list`
- pytest 옵션을 `-v --tb=short` 로 변경

### 결과
✅ Linux CI 통과 — `--disable-socket` 이 root cause 확정. `conftest.py` 의 FakeProvider monkeypatch 가 네트워크 차단의 주력 안전망이라 pytest-socket 은 *추가* 안전망일 뿐 없어도 외부 도달 가능성 0.
